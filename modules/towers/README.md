# Tower upgrades module

`upgrades.js` is the authoritative shared in-run upgrade engine: prices, purchase validation, attack stat scaling, shield capacity, damage absorption, orbit timing, hit flash and break effects. The main battle engine calls its public interface; no parallel shield implementation. The shield protects the tower only. The tower remains standing in its critical sprite at zero HP and the run ends as breached. Permanent equipment ownership, unlock validation and selection are managed through the same engine. `towers.json` owns tower, shield and drone catalog entries; the Upgrades page equips one of each. The selected loadout supplies the in-run configuration. Future shield/drone behaviors may extend the engine; the initial entries use the existing mirror and projectile behavior.
