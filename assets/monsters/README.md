# Monsters

All monster artwork belongs under `assets/monsters/`.

Existing `m001/` and `m002/` artwork remains for the current game. New production sprite sheets may be uploaded to the matching monster folder, e.g. `m001/mossguard_sheet.png` and `m002/cinderhorn_sheet.png`.

Sprite sheets are 4 rows × 4 columns, with monster poses only. Status effects and projectiles belong under `assets/effects/`.
